# Toomics 反爬调度参数说明

基于 anti-bot-model-v2 的行为仿真调度系统，通过以下参数控制爬虫的"阅读人格"和每日执行节奏。

---

## 总开关

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `antiBotEnabled` | boolean | `true` | `true`：启用反爬调度控制（时间窗口、配额、冷却等）。`false`：关闭所有调度逻辑，任务直通执行，不受任何限制。**建议生产环境为 `true`，调试时可临时关闭。** |

---

## 核心调度参数

### `dailyWindows`
每日时间窗口配置。不同天可配置不同窗口，故意错开避免形成规律。

```json
"dailyWindows": {
  "monday":    [{ "start": "12:00", "end": "22:30" }],
  "tuesday":   [{ "start": "18:30", "end": "22:00" }],
  "wednesday": [{ "start": "20:00", "end": "23:00" }],
  "thursday":  [{ "start": "18:00", "end": "21:30" }],
  "friday":    [{ "start": "19:30", "end": "23:30" }],
  "saturday":  [
    { "start": "10:00", "end": "12:00" },
    { "start": "15:00", "end": "17:00" },
    { "start": "20:00", "end": "23:30" }
  ],
  "sunday":    [
    { "start": "10:30", "end": "12:30" },
    { "start": "21:00", "end": "23:00" }
  ]
}
```

- 每天可配多个窗口（如周六 3 个时段、周日 2 个时段）
- 未配置的日期（当天数组为空）→ 全天允许执行
- 计划任务（cron）在窗口外触发时不会执行，需在窗口内才启动

### `windowJitterMinutes`
窗口随机偏移（分钟）。每次会话开始时，实际窗口整体偏移 ±N 分钟，进一步消除规律。

- 默认 `30`（窗口 start/end 各偏移 ±30 分钟）
- 设为 `0` 则禁用偏移，严格按照配置时间执行
- **原理**：如果每天都 19:00 准时上线，服务端可观察出规律。加上随机偏移后每天时间不同。

### `skipDayProbability`
每日跳过概率（0~1）。每天跨日重置时掷骰，N% 概率今天完全不执行。

- 默认 `0.12`（12%）
- 模拟真人"今天不想看漫画"的日子
- 设为 `0` 则每天必执行

### `sessionMaxMinutes`
单次会话最长时长（分钟）。超过此时间强制调用 `endSession()` 收尾退出。

- 默认 `45`
- 模拟真人不会连续刷一个多小时漫画
- 会话结束会触发冷却（见 `cooldownMinutes`）

### `sessionMinMinutes`
单次会话最短时长（分钟）。用于判断会话是否过短。

- 默认 `15`
- 避免"打开看了 2 分钟就走"的奇怪行为模式
- 当前实现中主要用于日志提示

---

## 会话间冷却

### `cooldownMinutes`
会话结束后必须等待的冷却时间（分钟），冷却期间不会开始新会话。

- 默认 `120`（2 小时）
- **生产环境建议**：如果一天只有一个窗口（如 4 小时窗口），建议缩短为 `30~60` 分钟，否则窗口内只能跑 1 场会话
- 冷却结束后，如果仍在时间窗口内，可开始新会话

---

## 每日配额

### `dailyQuota`
每天允许下载的章节数上限。只统计"真实下载"的章节，pretendNum 回翻章节不计入。

```json
"dailyQuota": {
  "monday":    12,
  "tuesday":   12,
  "wednesday": 12,
  "thursday":  12,
  "friday":    12,
  "saturday":  20,
  "sunday":    20
}
```

- 周末配额可设更高（消化工作日积压）
- 当日配额用完后，剩余任务顺延到下一个窗口/下一天
- 未配置配额的天默认 `12`

---

## 时间校验

### `timeCheckIntervalMinutes`
定期校验容器系统时间的时间间隔（分钟）。

- 默认 `30`
- 向外部 HTTP 时间源校验（防止容器时间漂移）

### `timeDriftThresholdMinutes`
时间漂移告警阈值（分钟）。

- 默认 `2`
- 偏差超此阈值记录告警日志

## 工作流程图

```
cron 触发
  ↓
检查 antiBotEnabled？ → false → 直通执行（不受任何限制）
  ↓ true
检查是否 toomics 任务？ → 否 → 直通执行
  ↓ 是
跨日重置（skipDayProbability 掷骰）
  ↓
今日跳过？ → 是 → 今日不执行
  ↓ 否
在时间窗口内？ → 否 → 等待下次触发
  ↓ 是
会话开始（加入 randomJitter 延迟）
  ↓
下载章节（受 dailyQuota 限制）
  ↓
每完成一部检查：
  ├─ sessionMaxMinutes 超时？ → endSession → 冷却
  ├─ dailyQuota 已满？      → 今日停止
  └─ 窗口结束？             → endSession → 冷却
  ↓
冷却中（cooldownMinutes）
  ↓ 冷却结束 + 仍在窗口内
下一场会话
```

## 快速参考表

| 场景 | `antiBotEnabled` | `cooldownMinutes` | 其他 |
|---|---|---|---|
| **生产环境** | `true` | `30~60` | 保持默认 |
| **手动调试** | `false` | 无关 | 所有参数忽略 |
| **调试行为逻辑** | `true` | `1` | `windowJitterMinutes: 0`, `skipDayProbability: 0` |
| **全天候爬取** | `true` | 删除当日 `dailyWindows` 条目 | 该天全天允许 |
